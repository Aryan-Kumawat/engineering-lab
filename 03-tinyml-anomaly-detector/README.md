# Compact Sensor Anomaly Detector

A reproducible normal-only training pipeline that learns mean/RMS feature distributions and exports quantized parameters. Python 3.10+, standard library only.

```sh
python detector.py --model model.json
python detector.py --model model.json --window 0.1,0.0,-0.1,0.2
```

The first command trains on 1,000 normal windows, saves a versioned JSON model, then evaluates on 500 independent normal and 500 synthetic faulty windows. Training and evaluation use different fixed seeds. The second command scores an actual window. For comparable scores use the training window length (32 samples) and the same units.

## Design

Each window becomes two features: mean and RMS. The training mean and standard deviation for each feature are quantized with a Q12 scale of 4096. The anomaly score is the largest absolute standardized feature distance, in thousandths. Scores above the fixed threshold of 5000 are anomalous. The threshold is chosen before evaluation, not tuned on test labels.

This is a compact statistical TinyML baseline. It is not a neural network. Feature extraction uses floating point; parameter storage and normalized scoring use integers. It has not been ported to a microcontroller or measured on hardware. Serialized JSON size is not a RAM measurement.

## Interpretation and limits

Synthetic faults have shifted mean and increased variance, so this dataset is intentionally easy. Precision/recall here do not predict performance on real motors. A production experiment needs real recordings, held-out machines, calibration and out-of-distribution evaluation. The two-feature model misses faults that preserve both moments. Retraining requires verified normal windows.

`train`, `score` and `evaluate` are importable functions for extending the experiment. Exported model files are trusted inputs generated by this program. Invalid samples are rejected.
