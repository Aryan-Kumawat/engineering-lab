# Project roadmap

## 01 — Sensor Log (Beginner)
Build a small C++ command-line program that reads simulated sensor samples, validates them, computes basic summaries, and reads CSV. Learn clean interfaces, parsing, error handling, and documentation.

## 02 — PID Playground (Beginner+)
Simulate a simple motor or temperature plant and compare proportional, PI, and PID controllers. Plot setpoint tracking and discuss overshoot, settling time, and stability.

## 03 — TinyML Anomaly Detector (Intermediate)
Train and evaluate a compact detector on generated or public sensor data. Compare a simple baseline with a small model, measure latency and memory, and document deployment constraints.

## 04 — Robot Telemetry (Advanced)
Design a local telemetry service with a versioned message format, bounded queues, reconnect behavior, structured logs, and a replay tool.

## 05 — Local Codebase Intelligence (Pro)
Build a local-first repository index and question-answering tool. Include source citations, deterministic retrieval baselines, a small evaluation set, and explicit failure behavior when evidence is missing.
