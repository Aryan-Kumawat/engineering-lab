# Changelog

## 0.1.0 — Initial source release

- Packaged Python CLI and desktop experiment workspace.
- Restricted serial URDF import and independent 3D forward kinematics.
- Seeded noise, quintic targets, PID control and surrogate joint dynamics.
- Effort/velocity diagnostics, geometric collision stops and hard joint-limit failures.
- Atomic result artifacts, replay, history, CSV signals and baseline comparison.
- Nominal, weak-controller and obstacle experiments.
- Numerical/integration checks and a repository CI workflow.

No full dynamics simulator, motion planner, ROS adapter or hardware execution is included in this version.
